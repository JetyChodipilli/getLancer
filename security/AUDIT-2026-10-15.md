## Findings addressed

| Finding | Impact and prerequisites | Correction |
| --- | --- | --- |
| Unbounded request-path DNS, CWE-400 | A submitted or stored external hostname can delay resolution while a profile, product, appeal or education request holds a database connection. Overall exhaustion was source-validated, not load-demonstrated. | Shared bounded DNS resolution: two daemon URL workers, no backlog, two-second caller deadline, saturation rejection and cancellation. Existing public-address checks remain; DemoHealth shares the bounded wait implementation. Native DNS may ignore cancellation, so worker and queue caps are essential. |
| Revoked inquiry confirmation context, CWE-863 | A holder of an unexpired consumed/revoked capability could still fetch private inquiry descriptions. | One database statement observes token state and context together. Consumed tokens retain only recorded-action metadata; restricted inquiries and inactive senders do not expose private context. Expired contexts remain rejected. |
| Credential clock mismatch, CWE-613 | Database/JVM clock skew could extend or prematurely end account-token, MFA-challenge or session validity. Actual production skew is unknown. | Database observations after credential locks determine expiry. Session expiry is generated in the database using the existing TTL. Cookie settings, TOTP verification and replay rules remain. |
| Email reuse inherits retained authority, CWE-863 | After operator-approved anonymization, a newly verified account using the released email could inherit old inquiries and private grants. | The privacy transaction rekeys retained inquiries to the closed identity and revokes email-bound grants and guest capabilities before releasing the address. Public inputs and OAuth account creation reject the closed-identity namespace. Historical ambiguity is handled by [V35](LEGACY-IDENTITY.md). |

## Verification and limits

New regressions cover every declared protected route, invalid session states, role/MFA denials, stalled DNS, mixed public/private DNS answers, token clocks, consumed/restricted context, email reuse, reserved identity names and historical requester migration. Positive controls preserve live confirmation context, legitimate DNS results, established owners and newly issued grants.

The token-clock and confirmation-privacy regressions were also run against unchanged baseline source: 10 tests produced five assertion failures and one expiry error, demonstrating the original defects. The corrected focused group passed 65 tests before the later identity migration additions. Thirty additional frontend/security-gate tests and seven SAST inventory tests passed locally. The full backend run exposed cached test connection exhaustion and a boundary-time analytics fixture; the candidate bounds the Spring test context cache to four and explicitly dates that historical review fixture. The backend rerun finished with 564 passing tests, zero assertion failures and one Windows symlink-privilege error in the existing LabProtocolTest; Linux CI must validate that test. Final exact-source results are recorded by the commit's CI checks.

The source audit remains partial. An independent baseline completed 73 full-file reviews; a broader continuation hit the account usage limit. An independent architecture map and focused pre-patch/candidate reviews completed, but architecture mapping, scanner coverage and passing tests do not imply a full manual review of every file. The provider-backed Deep Scan previously failed authentication; it is not claimed complete. Code Review's available connector is for pull-request CI diagnostics; this direct-main change does not have a PR review result.

The earlier selective one-million-project SQL benchmark is not a million-user concurrency test. Remaining capacity work includes common/deep-page queries, shared rate/audit writes, connection pressure, failover/restore and real edge/provider behavior. Hosted lab requests currently hold shared runtime settings locks over a bounded provider call; do not enable them for large-scale public traffic without a separate transaction/concurrency review and verified provider isolation.
