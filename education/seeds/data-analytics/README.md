# Synthetic sales analysis

Original dependency-free educational exercise. It is source only; no live platform review, hosted runtime or production purchase is implied.

## Setup

Install Python 3.11 or newer. No packages or credentials are required. Approximate setup: five minutes after the runtime is installed.

Run the regression first:

```sh
python3 test.py
python3 analysis.py
```

## Included and excluded

Exact Decimal aggregation of six original synthetic rows. No real customer data, interactive dashboard or business inference.
