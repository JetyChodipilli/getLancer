## Architecture and trust boundaries

The browser inspector reads free source metadata and original recordings. It does not start computation when a case is selected. `lib/data-ai.ts` pins the index source/archive identity to the compiled build manifest and every item to the checked-in catalogue. Bounded JSON transport, fatal UTF-8, duplicate-key detection, exact routes/fields/schema/units, original identities, input/result hashes, chronology and contextual metrics must pass before rendering. The UI captures each request's source/material, aborts on replacement and checks the active effect before accepting results. Rejected/stale evidence clears output. These checks establish consistency and version identity; they do not cryptographically authenticate arbitrary fabricated recordings or certify hosted work.

The local Python process accepts an operator UUID, four fixed scenarios and bounded form values. It binds only to loopback, supports no user-selected file, URL, loader, import or command, reads catalogue-pinned JSON assets and never runs seller uploads. The required LOCAL envelope deliberately echoes the bounded input; logs, errors and the result subtree do not. Published recordings contain only the original synthetic examples. Other programs on the local machine can reach this disposable process; loopback and OS limits are not tenant isolation.

Spring/PostgreSQL retain authenticated owner access, source eligibility, signed operator manifests, reservations, budgets, idempotency, lease generations and confirmed cleanup. Current authority is checked before provider work and after replies. The provider client fixes its origin, rejects redirects, bounds full response bytes/time and binds every reply to run/command/generation/epoch/manifest/image/expiry. Signed declarations and provider replies remain operational claims requiring independent real-provider verification.

Education's typed fifteen-field evidence remains optional/partial in drafts, required for new analytics/AI submission and forbidden for other categories. AI additionally needs frozen JSON model rights/provenance/hash and evaluation protocol. Current review revalidates present evidence; historical absence remains compatible. New snapshots and accepted agreements freeze evidence. Public releases, source offers, exports and buyer history share nested projections rather than rewriting immutable stored bytes. Owner academic annotations remain separately authorized/currently opted in.

## Findings, proofs and closure

1. **Historical component-link projection bypass — medium hardening priority, high confidence.** Generic nested `pick` accepted scalar arrays for textual attribution/licence/slug fields in public/export/buyer snapshots. Current overlay code could also copy raw attribution objects. Stored malformed historical data could therefore survive the new nested projection. No remote new-draft injection was demonstrated; new typed drafts already reject those types. Root added canonical UUID, positive integral-long revision, maximum twenty links, bounded text and valid hash projection. Education/commerce overlays consume projected links and copy normalized identity/string attribution. `EducationService.dto` passes `schema.publicView(snapshot)` to the sole non-required component-read path. Reviewed Java regressions contain array/object/numeric/boolean canaries, malformed identities/revisions and valid attribution/licence controls, preserving stored snapshot bytes. Code closure is confirmed; final native integration execution belongs to CI.

2. **Deep source JSON printed a startup traceback — low severity, confidence10/10.** An independently copied clean package reached readiness and executed. Replacing its model with a20,001-byte JSON array nested10,000 levels and updating its pinned hash triggered an uncaught `RecursionError`, exposing absolute local/interpreter paths in stderr despite the file being below32 KiB. Requests cannot select these bytes; the defect was at the source/configuration boundary, with no remote code-execution claim. Root now converts decoder `RecursionError` to `ValueError` in `read_json`, reaching the fixed startup rejection. The same original positive and hostile case passed afterward without traceback; source, archive, recordings and compiled build pins were regenerated.

No unresolved confirmed defect remains in this focused source/runtime/parser/projection/control-policy review. The custom HTTP reader is justified by the absolute-deadline requirement; the implementation adds no dependency, executable loader or separate payment authority. New public projection uses the existing shared adapter instead of another parallel serializer.
