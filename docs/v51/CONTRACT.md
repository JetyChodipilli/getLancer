# V5.1 implementation contract

Baseline: main fb7b1a7, merged V5.0. Scope is all S07-B01 through S07-B08 from the full V4.5–V5.2 roadmap and backlog, not only IoT.

## Required outcomes
1. IoT content: original licensed ESP32-style C++ and MicroPython firmware examples, BOM, wiring, dependencies/power/cost exclusions, dated physical proof represented honestly (none supplied), and reviewed per-run MQTT topic/input contract.
2. Protocol/device simulation: free interactive browser-local simulation plus real account-free local MQTT wire/HTTP reproduction; publish changed synthetic temperature/humidity/threshold, observe broker/device state and logs; disconnect/reconnect/reset; reject foreign run/topics, malformed packets, oversized input and unbounded resource requests. No physical control or external paid embed.
3. Three native backend adapters (Go, C#/.NET, PHP), each implementing cache/security/payment contracts and the existing normal/failure matrix. Eighteen core labs total. Clean extracted source reproduction, original licenses, bounded protocol/expiry and native startup/resource evidence.
4. Vue/Svelte/Angular original framework source, pinned dependencies and framework-specific setup. Trusted CI builds reviewed isolated static previews; iframe cannot access app accounts, network or navigation. Sources remain free.
5. Explicit language/framework/runtime/scenario coverage and inactive/unsupported certification behavior: source remains visible while uncertified, disabled, expired or retired execution fails closed. Signed provider evidence and existing operator authority remain mandatory for hosted activation.
6. End-to-end tests, negative/security cases, responsive accessibility, clean builds, source/hash bindings, docs, successful current-head CI and merge into main. Preserve all existing account, source-commerce, runtime budget and privacy boundaries.

## Shared contracts
- Backend patterns match existing labs/java, labs/python and labs/typescript exactly: loopback /health and bounded form POST /request, UUID run, primary source hash, typed state/events, monotonic sequence, public synthetic HMAC fixture. Payment is emulator only; cache uses pinned real Redis 7.2.16; current roles and tenant boundaries are checked each request.
- New languages catalogue keys: go, dotnet, php; primary paths labs/go/server.go, labs/dotnet/Program.cs, labs/php/server.php. Commands: go run labs/go/server.go; dotnet run --project labs/dotnet/LabServer.csproj --no-launch-profile; php labs/php/server.php. No application dependency additions.
- IoT pure browser contract in lib/iot.ts: createIotSession(runId?:string, now?:number): IotSession; iotAction(state, action, now?:number): IotSession. Actions {type:'publish',temperatureC:number,humidityPercent:number,thresholdC:number,topic?:string}, {type:'disconnect'}, {type:'connect'}, {type:'reset'}. IotSession fields runId, connected, temperatureC, humidityPercent, thresholdC, actuatorOn, sequence, topic, messages and events. Exact topic getlancer/<UUID>/telemetry; bounds -20..80 C, 0..100%, threshold 0..60 C; QoS0 MQTT subset, no arbitrary destinations/physical devices. Runtime uses the same reviewed bounds with actual MQTT packets on local loopback.
- Frontend route /labs/iot; frameworks /components/frameworks with same-origin sandboxed preview assets. Preserve Spectral Studio, 16px inputs, 44px actions, reduced motion, clear labels and errors. Root integrates menu links and existing UI polish from the separately published preview only where in scope.
- New hosted IOT_SIMULATION policy is an independent disabled-by-default gate; it never bypasses APP_LABS_ENABLED, signed manifests, current image/source identity, reservations, provider admission or cleanup. No arbitrary simulator upload executes.
- root owns shared catalogues, matrix verifier/packager, CI/Docker, existing scenario evidence parser, menu links, source audit, phase docs and acceptance; leaves own only their listed paths. Do not alter another leaf’s files, install hooks, commit, push or run whole-project builds concurrently. Native agents must return limitations honestly.
