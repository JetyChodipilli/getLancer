# V4.9 implementation contract

S05 of the uploaded GetLancer V4.5–V5.2 plan. Baseline da530f7 (V4.8). Separate new education domain; preserve existing account, product/contribution/capacity, commerce and hosting authority. Code completion and live merchant activation are separate: APP_EDUCATION_PAID_ENABLED defaults false; no provider purchase/provisioning.

## Shared interfaces (revision 1)

Education release: UUID id/productId; revision; status DRAFT/PENDING/APPROVED/CHANGES_REQUESTED/SUSPENDED; sourceHash; snapshot (immutable after submit); current academic/private details separate. snapshot has productId, slug, title, summary, category FULL_STACK/DATA_ANALYTICS/AI_ML/IOT, mode SHOWCASE/FREE/PAID, difficulty BEGINNER/INTERMEDIATE/ADVANCED, demoMode SOURCE_ONLY/EXTERNAL/HOSTED, demoUrl, package (includedAssets, excludedAssets, setupSteps, prerequisites, limitations arrays and supportTerms/licenseTerms strings), categoryEvidence concrete bounded fields, contribution (existing authority), componentLinks with exact componentId/revision/license/attribution, sourceBinding {packageId OR versionId,sha256,sizeBytes,files,licenseTerms}, priceMinor/currency for PAID only. Current host availability and component/profile eligibility overlay never changes frozen terms. Never include storage keys in public snapshots or exports.
