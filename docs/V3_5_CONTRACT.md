# V3.5 source marketplace contract

Revision 1 — 1 October 2026. Build on main 24c2d046207878b6d12a106a2444dcdce60a789f. Java/PostgreSQL is the only backend; frontend previews are isolated. No source execution, public archive URLs, live secrets or demo seeds. Only the demo frontend may be cloud deployed.

## Scope
Approved individual builders sell versioned source packages tied to their approved public proof product. A repository ownership verification plus explicit seller rights consent and MFA operator package review is required; ownership verification is not a copyright warranty. Teams retain V3 delivery but individual sellers own V3.5 templates initially. Licenses allow one commercial end product, modification, and no redistribution of source as a competing template. A seller supplies license terms and release notes; operator reviews third-party notices and README. Terms and immutable package SHA-256 are frozen per purchase. No arbitrary code execution, escrow, fees or subscriptions.

## API and JSON
All paths under /api/v1. Collection responses use Pages.query: items,page,size,hasMore,totalItems,totalPages. Public template fields: id,slug,title,summary,description,category,technology,priceMinor,currency (INR),productId,productSlug,sellerId,sellerName,versionId,version,releaseNotes,licenseTerms,status,createdAt. Private owner/operator version fields additionally include reviewReason,sha256,sizeBytes,entryCount. Never expose storage keys publicly.

- GET /templates?q=&category=&technology=&page=0&size=12; GET /templates/{slug} returns template plus versions (approved metadata only).
- GET /me/templates returns owned templates; POST /me/templates body {productId,title,summary,description,priceMinor,licenseTerms}; returns detail. Seller must currently be approved and own approved public product.
- POST /me/templates/{id}/versions multipart fields file (ZIP), version, releaseNotes,rightsConsent=true; returns version. Bound compressed ZIP <=5MiB, expanded <=25MiB, entries <=500; reject traversal, duplicate names, symlinks, executable binaries, secrets, invalid ZIP and unsafe paths. Require README and LICENSE/license notices. Store private randomized immutable copy; never run submitted code.
- POST /me/templates/{id}/versions/{versionId}/submit body {rightsConsent:true}; POST /me/templates/{id}/archive; reviewed versions are immutable. New release has independent review; existing buyer purchase remains pinned to its version. Archiving removes discovery/new checkout but preserves eligible purchases. Operator suspension revokes downloads.
- GET /admin/templates returns pending/reviewed templates+versions; POST /admin/templates/{id}/versions/{versionId}/review body {action:'APPROVE'|'CHANGES_REQUESTED'|'REJECT'|'SUSPEND',reason,rightsReviewed:true,packageReviewed:true}; MFA only. GET /admin/templates/{id}/versions/{versionId}/package downloads for review. Owner can GET /me/templates/{id}/versions/{versionId}/package. Source response attachment application/zip,nosniff,private no-store.
- GET /me/template-purchases; POST /templates/{id}/orders body {versionId,licenseConsent:true}, Idempotency-Key random UUID. Frozen server-selected price/account/version/license. Return {id,orderId,amountMinor,currency,keyId,mode,status}. Block self-purchase, unapproved/suspended seller, pending package and missing consent. One current purchase/order per buyer+version+mode; commit reservation before provider call. Unknown create blocks retry until MFA recovery.
- POST /template-purchases/{id}/verify body {razorpay_payment_id,razorpay_signature}; POST /template-purchases/{id}/reconcile; POST /template-purchases/{id}/disputes body {reason}; GET /template-purchases/{id}/download. Download only current authenticated buyer with live CAPTURED, no confirmed refund/dispute, active buyer, approved eligible seller and unsuspended package. Test captures never grant real source entitlement. Buyer history includes immutable title,version,licenseTerms,sha256,amountMinor,currency,mode,status,refundedMinor,downloadAvailable,dispute status.
- POST /commerce/razorpay/webhook exact signed raw bounded body, event-id dedup, provider authoritative reconciliation (same gateway and credentials; second configured endpoint).
- GET /admin/template-purchases/attention; POST /admin/template-purchases/{id}/bind-order body {orderId}; POST /admin/template-purchases/{id}/reconcile; POST /admin/template-purchases/{id}/resolve body {resolution:'RESUME'|'REVOKE',reason}. MFA recovery checks receipt/amount/payee/currency and refund/dispute holds cannot be cleared by local resolution.
