# Original native framework previews

Three isolated, lockfile-pinned examples: Vue reactive project brief, Svelte build queue, and Angular release checklist. These compile with the real Vue/Svelte/Angular compilers and ship a bundled runtime, not a React emulation or external CDN. See each README for exact local setup and rights.

Trusted CI: `node scripts/build-framework-material.mjs --native --verify` installs each lockfile with lifecycle scripts disabled, executes the reviewed native build, and checks committed material against source and generated bytes. `node scripts/build-framework-material.mjs --native` regenerates reviewed material. The normal application build verifies material without executing framework compilers. Never invoke this pipeline on uploads or caller-chosen paths/packages.

After the native build, run `node --test tests/framework-portability.native.mjs` from the repository root. It rebuilds Vue and Svelte from temporary directories containing spaces and escaped URL characters, reuses the installed pinned compilers without network access, and compares the resulting JavaScript and CSS bytes with the original build.
